# 模块说明：缓存（cache）

**包**：`io.github.sinri.keel.core.cache`  
**版本线**：5.0.1（与 keel-core 一致）

## 职责

提供进程内、带过期策略的缓存抽象：同步读写外观、可选异步外观，以及默认实现与「空实现」（不缓存），便于业务与测试替换。

## 主要类型

| 类型                                                          | 说明                              |
|-------------------------------------------------------------|---------------------------------|
| `KeelCacheInterface<K,V>`                                   | 同步缓存主入口，继承 `KeelSyncCacheAlike` |
| `KeelSyncCacheAlike<K,V>`                                   | 同步读写的缓存外观                       |
| `KeelAsyncCacheAlike<K,V>` / `KeelAsyncCacheInterface<K,V>` | 异步外观与接口                         |
| `KeelCacheImpl`                                             | 默认实现（包内，通过工厂获得）                 |
| `KeelCacheDummy<K,V>`                                       | 不保存任何条目的伪实现                     |
| `NotCached`                                                 | 与读取/计算相关的异常类型                   |

## 工厂与典型用法

- **默认实现**：`KeelCacheInterface.createDefaultInstance()`
- **测试或关闭缓存**：`KeelCacheInterface.getDummyInstance()`

常用能力（以接口 JavaDoc 为准）：

- 配置 **默认 TTL**：`setDefaultLifeInSeconds(long)`
- **按 key 存取**：`save`、`read` 等
- **不存在则计算并写入**：接口中基于 `Function` / `Supplier` 的便捷方法

## 注意事项

- 缓存为 **进程内** 语义，多实例部署时彼此不共享。
- 具体是否使用 `SoftReference`、并发策略等以 `KeelCacheImpl` 实现与 JavaDoc 为准。
